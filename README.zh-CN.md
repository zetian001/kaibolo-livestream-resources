# 开播咯 · 直播实用资料

[中文网站](https://kaibolo.com/) · [English website](https://kaibolo.com/en/) · [English README](README.md)

开播咯是面向主播、直播运营和机构团队的成长知识库，整理了新人入门、直播话术、内容策划、观众互动、设备搭建与行业动态。网站现已提供中英文版本，海外读者也可以用英文浏览完整资料。

这个仓库提供两份配套模板：开播前检查清单和下播复盘表。遇到具体问题时，先找到对应学习资料，再把准备事项、实际表现和下一场要测试的改进记录下来。

## 两份可以直接用的模板

1. 开播前，逐项核对[开播检查清单](PRE-STREAM-CHECKLIST.md)。
2. 下播后，填写[直播复盘模板](STREAM-REVIEW-TEMPLATE.md)。
3. 下一场只选一个主要改进点，记录结果，再决定是否继续。

两份模板均提供中英文内容。
